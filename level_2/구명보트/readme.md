프로그래머스 : 구명보트

**풀이**

- 기본 값을 1인 1보트 개수만큼을 설정
- 사람 몸무게 배열을 오름차순 정렬
- 양 끝을 가리키는 left, right 투 포인터를 설정
- 가장 가벼운 사람과 무거운 사람의 합이 limit 이하이면 함께 탑승함으로 boat 개수 감소
- 초과하면 right만 감소


**핵심 코드**

```java
while (left < right) {
    
    // 몸무게가 큰 사람과 작은사람으로 무게 측정
    if (people[left] + people[right] <= limit) {
        
        left++;
        right--;
        
        // 해당 두 사람일 때 같은 배를 탈 수 있으므로, 배 총량 감소
        boat--;
    } else {
        
        // 무게 제한 초과임으로 더 낮은 무게 사람 위치로 이동
        right--;
    }
}
```
