### 문제 이름 : 짝지어 제거하기

- **문제 사이트** : https://school.programmers.co.kr/learn/courses/30/lessons/12973
- **Level** : 2
- **알고리즘 유형** : *Stack*

---

### 풀이

1. 문자열을 앞에서부터 한 글자씩 확인한다.
2. 현재 문자가 스택 최상단 문자와 같으면 제거한다.
3. 같지 않으면 스택에 추가한다.
4. 짝이 되는 문자는 즉시 제거한다.
5. 모든 문자를 확인한 뒤 스택이 비어있으면 성공이다.
6. 스택이 비어있으면 1, 아니면 0을 반환한다.

---

### 핵심 코드

<details>
<summary>핵심 코드 보기</summary>

```java
for (char c : chars) {

    // 현재 문자와 스택 최상단 문자가 같으면 제거
    if (!st.empty() && st.peek() == c) {
        st.pop();
    // 다르면 스택에 추가
    } else {
        st.push(c);
    }
}

return st.empty() ? 1 : 0;
```

- 스택을 이용하여 인접한 같은 문자를 관리한다.
- 짝이 되는 문자는 즉시 제거한다.
- 최종적으로 스택이 비어있으면 모든 문자를 제거한 상태이다.

</details>
