### 문제 이름 : 예상 대진표

- **문제 사이트** : https://school.programmers.co.kr/learn/courses/30/lessons/12985
- **Level** : 2
- **알고리즘 유형** : Bit Masking

---

### 풀이

1. 두 참가자의 번호가 같아질 때까지 반복
2. 홀수 번호는 +1 하여 짝수 번호로 변환
3. 비트 연산으로 2를 나누어 다음 라운드 번호 계산
4. 라운드가 진행될 때마다 횟수 증가
5. 두 번호가 같아지는 순간 정답 반환

---

### 핵심 코드

<details>
<summary>핵심 코드 보기</summary>

```java
while (a != b) {
            
    // 짝수 만들기
    if ((a & 1) == 1) {
        a += 1;
    }

    if ((b & 1) == 1) {
        b += 1;
    }
    
    // 다음 라운드 이동
    a = a >> 1;
    b = b >> 1;
    
    // 라운드 횟수 증가
    answer++;
}
```

- 비트 연산으로 홀수 여부 확인
- 오른쪽 시프트로 다음 라운드 번호 계산
- 번호가 같아질 때까지 반복
- 추가 자료구조 없이 O(log N)으로 해결
